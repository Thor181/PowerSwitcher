# PowerSwitcher

Утилита для Windows 11, которая переключает настройки питания и дисплея одним кликом из области уведомлений. Настройки объединяются в **профили** («Игры», «Работа», «Экономия» и т. п.), а профиль можно применять вручную или автоматически — при подключении зарядки, переходе на батарею и низком заряде.

## Возможности

Профиль может включать любой набор из следующих параметров (незаданные параметры не трогаются):

| Параметр | Что меняет |
|---|---|
| Частота обновления | Герцовка выбранного монитора |
| Схема питания | Активная схема электропитания Windows |
| Режим питания | «Лучшая энергоэффективность» / «Сбалансированный» / «Максимальная производительность» |
| Turbo Boost | Режим повышения частоты процессора (отключён, включён, агрессивный, эффективный и др.) |
| Макс. состояние процессора | Ограничение в процентах (99% и ниже отключает турбо) |
| EPP | Приоритет энергоэффективности: 0 — производительность, 100 — экономия |
| Отключение экрана / сон | Таймауты в секундах (0 — никогда) |
| Яркость | Уровень яркости встроенного дисплея и адаптивная яркость |
| Экономия энергии | Режим Energy Saver |

**Автопереключение** — отдельные профили для работы от сети, от батареи и при низком заряде (порог по умолчанию — 20%). Профиль применяется только при смене условий, поэтому ручной выбор не перебивается на каждом изменении процента заряда. О срабатывании приходит уведомление.

**Интерфейс** — флайаут в стиле Windows 11 с фоном Mica и скруглёнными углами, светлая и тёмная темы по системной, значок в трее (левый клик — открыть, правый — меню).

## Требования

- Windows 11 (Mica — начиная с 22H2, сборка 22621; на более старых сборках используется сплошной фон)
- [.NET 10 SDK](https://dotnet.microsoft.com/download) для сборки
- Права администратора — приложение запрашивает их при запуске (`requireAdministrator`), без них Windows не даёт менять часть параметров питания

## Сборка и запуск

```powershell
git clone https://github.com/Thor181/PowerSwitcher.git
cd PowerSwitcher
dotnet build PowerSwitcher.slnx -c Release
dotnet run --project PowerSwitcher.App -c Release
```

Публикация в один исполняемый файл:

```powershell
dotnet publish PowerSwitcher.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

## Структура проекта

```
PowerSwitcher.Core      библиотека: профили, применение настроек, работа с WinAPI и WMI
PowerSwitcher.App       WPF-приложение: флайаут, значок в трее, автопереключение, темы
PowerSwitcher.TestApp   консольная песочница для проверки Core
```

Основные классы `PowerSwitcher.Core`:

- `PowerProfile` — модель профиля
- `ProfileApplier` — применяет профиль и возвращает результат по каждому параметру
- `PowerManager` — схемы и режимы питания, Turbo Boost, EPP, таймауты (`powrprof.dll`)
- `DisplayManager` — список мониторов и частоты обновления (`user32.dll`)
- `BrightnessManager` — яркость через WMI
- `BatteryMonitor` — состояние батареи и источника питания
- `AutoSwitchSettings` / `AutoSwitchPolicy` — правила автопереключения
- `ProfileStore` — сохранение профилей и настроек в JSON

## Где хранятся данные

`%APPDATA%\PowerSwitcher\`:

- `profiles.json` — профили
- `settings.json` — настройки автопереключения
- `current-profile.json` — последний применённый профиль
